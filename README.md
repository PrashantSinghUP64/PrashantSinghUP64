### 🎯 [PlacementOS](https://placement-os-mu.vercel.app/)
> *"I built PlacementOS because I wanted placement prep to be less stressful and more intelligent for every engineering student in India."*

**PlacementOS** is an AI-powered, all-in-one placement preparation platform built specifically for Indian engineering students — transforming how they prepare for tech interviews and campus placements.

**✨ What makes it special:**
- 🤖 &nbsp;AI-driven mock interviews with real-time feedback
- 📚 &nbsp;Curated DSA roadmaps + company-wise question banks
- 📊 &nbsp;Performance analytics & progress tracking dashboard
- 🎯 &nbsp;Resume builder with ATS score checker
- 🗓️ &nbsp;Smart study scheduler powered by spaced repetition
- 🔔 &nbsp;Real-time placement drive notifications

**🛠️ Built With:**
